OceanBase Dashboard: oceanbase-dashboard-{{ .Release.Name }}

Open a local connection after the Deployment becomes Ready:
  kubectl -n {{ .Release.Namespace }} port-forward svc/oceanbase-dashboard-{{ .Release.Name }} 18081:{{ .Values.service.port }}
Then visit http://127.0.0.1:18081 on the computer running port-forward.
When running this on a remote server, use an SSH tunnel to that server's loopback port.
{{ if eq .Values.service.type "NodePort" }}
The Service also uses NodePort. Inspect the allocated port with:
  kubectl -n {{ .Release.Namespace }} get svc oceanbase-dashboard-{{ .Release.Name }}
{{ end }}
{{ if .Values.initCredentials }}
Initial username: admin.
On first installation, the password is the configured adminPassword value
(the standalone chart default is "admin"). Change it on first login.
For an existing installation with retained credentials, use the current password;
changing Helm values does not reset a retained account.
{{ else }}
Account initialization is managed outside this Dashboard chart.
Use the account and current password supplied by the parent installer or the
administrator of Secret {{ .Values.userCredentials | default (printf "%s-user-credentials" .Release.Name) }}
in namespace {{ .Values.userNamespace | default .Release.Namespace }}.
For the oceanbase-lakehouse parent chart, username is admin and the INITIAL
password is in Secret {{ .Release.Name }}-dashboard-bootstrap (key: password).
After changing the password, use the new password instead of the bootstrap value.
{{ end }}
