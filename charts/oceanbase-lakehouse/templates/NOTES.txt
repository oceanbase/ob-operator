  kubectl -n {{ .Release.Namespace }} get oblogservicecluster/{{ .Release.Name }}-ls obcluster/{{ .Release.Name }}-ob

  kubectl -n {{ .Release.Namespace }} logs job/{{ .Release.Name }}-readiness
Retry with the SAME release, namespace and values using helm upgrade --install.

  kubectl -n {{ .Release.Namespace }} port-forward svc/oceanbase-dashboard-{{ .Release.Name }} 8080:{{ .Values.dashboard.service.port }}
Open http://127.0.0.1:8080 on the computer running port-forward.
Login: admin. Retrieve the INITIAL password:
  kubectl -n {{ .Release.Namespace }} get secret {{ .Release.Name }}-dashboard-bootstrap -o jsonpath='{.data.password}' | base64 --decode; echo
After changing the password in Dashboard, use that new password.

List Observer Pods and forward one to a SQL client on this computer:
  kubectl -n {{ .Release.Namespace }} get pods -l ref-obcluster={{ .Release.Name }}-ob
  kubectl -n {{ .Release.Namespace }} port-forward pod/<observer-pod-name> 12881:2881
