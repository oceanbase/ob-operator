Retry and recovery
After fixing image access, capacity, storage initialization or credentials,
retry with the SAME release, namespace and values using helm upgrade --install.
If OBCluster or OBLogServiceCluster has status failed, a Helm retry does not
reset it. Inspect events and follow the Operator recovery procedure in USAGE.txt:
  kubectl -n {{ .Release.Namespace }} get events --sort-by=.lastTimestamp

DATA PROTECTION: uninstall intentionally retains database CRs, credentials and
bundled MinIO StatefulSet/Service/PVC, plus Dashboard accounts and data PVCs.
Namespace deletion or explicit Kubernetes deletion is NOT protected. Keep backups.
Reinstall with the SAME release, namespace and values to reconnect retained data.
External storage and user-provided Secrets/PVCs are never owned by this chart.
