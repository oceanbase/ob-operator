QA image closure gate (build-time only)
=====================================
Requires Python >= 3.8 and PyYAML in an isolated build environment.

Render all enabled components with the actual QA image overrides:
  helm template operator PACKAGE/charts/ob-operator > operator.yaml
  helm template lakehouse PACKAGE/charts/oceanbase-lakehouse \
    -f PACKAGE/values/quickstart.yaml --set stage=cluster \
    --set-string storageClass=local-path > lakehouse.yaml
  helm template dashboard PACKAGE/charts/oceanbase-dashboard \
    --set-string adminPassword=render-only-not-an-account > dashboard.yaml

Then verify the actual fresh extraction of the single-tar delivery:
  python3 scripts/qa/verify-image-closure.py PACKAGE/image-lock.json \
    operator.yaml lakehouse.yaml dashboard.yaml \
    PACKAGE/prerequisites/cert-manager-v1.12.4.yaml --bundle PACKAGE

--bundle verifies the internal SHA256SUMS and images/archives.json, requires
every image to use delivery=archive and every archive to use base=bundle, and
rejects missing files, checksum mismatches, symlinks and escaping paths. Each
archive's actual image references must match its declared references, and all
config IDs must match image-lock.json. MinIO/mc is validated inside
PACKAGE/images/minio-images.tar.gz along with the other bundled archives.
No external checksum or image sidecar is required.

Missing container images (including oceanbase/kube-rbac-proxy:v0.13.1), missing archive
entries, wrong config image IDs, duplicate refs and untracked images fail the
build. IDs are computed from the actual Docker-save config bytes (both legacy
and OCI blob paths), not trusted from config filenames or manifest digests.
The Dashboard ConfigMap's inspection tool images are included in closure checks
because they run in dynamically created diagnostic jobs. The optional SQL
analyzer remains outside this delivery scope.

The diagnostics archive normally contains obdiag, oceanbase-helper and the
updated Dashboard. Observer remains in the original core archive with its
original image ID; it is not required to appear in the diagnostics archive.
Check the rendered upgrade with the existing release values followed by
values/diagnostics-upgrade.yaml: the OBCluster Observer image must stay unchanged.
The fixture suite covers both archive closure and this Helm overlay behavior.

For older packages, omit --bundle and pass their archives explicitly with
--archive and --sidecar-archive. Legacy delivery-sidecar entries (including
MinIO/mc) must appear only in the separately supplied --sidecar-archive;
online-or-matching-existing-cache entries cannot silently appear in an archive.
The single-tar gate does not accept either legacy delivery mode or external
archive arguments. The fixtures retain old-format compatibility coverage and
also copy just one complete tar to an empty directory before validating it.
Run tests with: python3 -m unittest discover -s scripts/qa -p 'test_*.py'

Rendered YAML can contain generated or supplied credentials. Keep rendering
files private in the build workspace; do not include real Secret manifests in
the QA bundle or logs. This gate does not install software or modify a cluster.
It validates only supplied manifests: render every component you intend to ship.
